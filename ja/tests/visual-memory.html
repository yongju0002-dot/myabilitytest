瞬間記憶力テストとは?

このテストは空間ワーキングメモリ(spatial working memory)、つまり複数の場所を一瞬で覚えて思い出す能力を測定します。画面に一瞬表示されたマスの位置を、順不同ですべてクリックして当てる形式です。レベルが上がるごとにマスが1つずつ増えるので、どのレベルで間違えるかが空間記憶の容量の目安になります。

レベルはどう上がりますか?

レベル1では3マスを記憶し、レベルが1つ上がるごとにマスが1つ増えます(レベルN=N+2マス)。一度でも間違えるとそのレベルで終了し、到達した最高レベルが最終記録になります。

記憶力を伸ばす方法はありますか?

心理学でよく言われる「チャンキング(chunking)」が有効とされています。マスを1つずつ覚えるのではなく、三角形・対角線・十字のような1つの形として捉えると、より多くのマスを一度に記憶しやすくなります。画面中央に視線を固定し、周辺視野で全体の配置を捉える練習も役立つと言われています。

視覺記憶測驗指南

視覺記憶測驗量的是什麼?

這項測驗量的是空間工作記憶——短暫保留並回想多個項目位置的能力。方塊會在畫面上閃現片刻,然後你要把它們全部點回來,順序不限。每一級都會多加一個方塊,因此你最終出錯的那一級,大致就是你空間記憶廣度的量尺。

平均是多少?怎樣算好成績?

依本站的量表,第 5–8 級(7–10 個方塊)屬於一般,9–12 級算不錯,16 級以上則是優秀區間。這是我們自訂的區間,不是官方統計。

第 N 級要記住 N+2 個方塊,因此把表格裡的等級換算成方塊數,大致就能看出你的空間工作記憶容量。

等級是怎麼運作的?

第 1 級顯示 3 個方塊,之後每升一級剛好多一個(第 N 級 = N+2 個方塊)。點錯一次就結束,最終成績是你抵達的最高等級。

要怎麼進步?

分組記憶(chunking)——把方塊組成一個形狀(三角形、對角線、十字),而不是逐一死記——是經典的記憶技巧,在這裡通常很有幫助。把視線固定在格狀中央附近、用周邊視覺一次收下整體排列,也是很多人覺得有效的另一種做法。

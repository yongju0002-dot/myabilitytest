Visual Memory Test guide

What does the Visual Memory Test measure?

This test measures spatial working memory - your ability to briefly hold and recall the positions of several items at once. Tiles flash on screen for a moment, and you click them all back in any order. Each level adds one more tile, so the level where you finally slip up is a rough gauge of your spatial memory span.

What's average, and what's a good score?

On this site's scale, levels 5–8 (7–10 tiles) is ordinary, 9–12 is good, and 16+ is the excellent band. These are our own grade bands, not official statistics.

Level N asks you to remember N+2 tiles, so converting the table's levels to tile counts gives a rough sense of your spatial working-memory capacity.

How does leveling work?

Level 1 shows 3 tiles, and each level up adds exactly one more (level N = N+2 tiles). One wrong click ends the run, and your final score is the highest level you reached.

How can I improve?

Chunking - grouping tiles into a shape (a triangle, a diagonal line, a cross) instead of memorizing each one individually - is a classic memory technique that tends to help here. Keeping your eyes fixed near the center of the grid and using peripheral vision to take in the whole layout at once is another approach that works well for a lot of players.
